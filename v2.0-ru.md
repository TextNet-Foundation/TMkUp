## 1. Введение

TMkUp (Text Markup) — язык разметки для текстовой сети **TNet**. Он предназначен для создания документов, которые:

- Читаемы человеком в исходном виде.
- Поддерживают цвета ANSI и базовое форматирование.
- Содержат интерактивные элементы (формы, спойлеры) для клиентов, которые их поддерживают.

**Основные принципы:**
- Простота и читаемость.
- Единый синтаксис для всех элементов.
- Минимализм — никаких условных блоков, только статическая разметка.
- Расширяемость за счёт версионирования.

## 2. Структура документа

Документ может начинаться с необязательного блока метаданных:

```tmkup
---tmk-meta
title: "Document Title"
author: "Author Name"
version: "2.0"
created: "2024-06-10"
variables:
  site_name: "TNet Hub"
---tmk-meta
```

Метаданные могут содержать произвольные ключи. Клиенты могут использовать их для отображения информации о документе.

## 3. Базовое форматирование

### Заголовки

```tmkup
# Heading 1 #
## Heading 2 ##
### Heading 3 ###
#### Heading 4 ####
##### Heading 5 #####
###### Heading 6 ######
```

### Стили текста

```tmkup
*italic*
**bold**
***bold italic***
~~strikethrough~~       (необязательно)
==highlight==            (необязательно)
`inline code`
^superscript^
~subscript~
```

### Горизонтальные разделители

```tmkup
---
***
```

## 4. Цвета ANSI

Цвета задаются с помощью тегов `{color}...{/color}`. Для стилей текста (жирный, курсив и т. д.) отдельные теги не используются — вместо них применяются `*` и `**`.

```tmkup
{red}Красный текст{/red}
{green}Зелёный текст{/green}
{blue}Синий текст{/blue}
{yellow}Жёлтый текст{/yellow}
{magenta}Пурпурный текст{/magenta}
{cyan}Голубой текст{/cyan}
{white}Белый текст{/white}
{black}Чёрный текст{/black}

{bg-red}Красный фон{/bg-red}
{bg-green}Зелёный фон{/bg-green}
{bg-blue}Синий фон{/bg-blue}
{bg-yellow}Жёлтый фон{/bg-yellow}
{bg-magenta}Пурпурный фон{/bg-magenta}
{bg-cyan}Голубой фон{/bg-cyan}
{bg-white}Белый фон{/bg-white}
{bg-black}Чёрный фон{/bg-black}
```

**Яркие цвета:**

```tmkup
{bred}Яркий красный{/bred}
{bgreen}Яркий зелёный{/bgreen}
{byellow}Яркий жёлтый{/byellow}
{bblue}Яркий синий{/bblue}
{bmagenta}Яркий пурпурный{/bmagenta}
{bcyan}Яркий голубой{/bcyan}
{bwhite}Яркий белый{/bwhite}
{bblack}Яркий чёрный{/bblack}
```

**Яркие цвета фона:**

```tmkup
{bg-bred}Яркий красный фон{/bg-bred}
{bg-bgreen}Яркий зелёный фон{/bg-bgreen}
{bg-byellow}Яркий жёлтый фон{/bg-byellow}
{bg-bblue}Яркий синий фон{/bg-bblue}
{bg-bmagenta}Яркий пурпурный фон{/bg-bmagenta}
{bg-bcyan}Яркий голубой фон{/bg-bcyan}
{bg-bwhite}Яркий белый фон{/bg-bwhite}
{bg-bblack}Яркий чёрный фон{/bg-bblack}
```

**Сочетание цвета и стиля:**

```tmkup
{red}*Красный курсив*{/red}
{green}**Зелёный жирный текст**{/green}
{blue}***Синий жирный курсив***{/blue}
{red}Красный {green}зелёный внутри{/green} снова красный{/red}
```

**Сброс всех стилей:**

```tmkup
{red}Красный текст **{/}** и теперь обычный
```

## 5. Списки

### Ненумерованный список

```tmkup
- Элемент 1
- Элемент 2
  - Вложенный элемент
    - Глубокий уровень
```

### Нумерованный список

```tmkup
1. Первый элемент
2. Второй элемент
   1. Вложенный элемент
   2. Ещё один элемент
```

### Список задач

```tmkup
- [ ] Невыполненная задача
- [x] Выполненная задача
- [~] Задача в процессе
```

### Список определений

```tmkup
Термин 1
: Определение первого термина
: Второе определение

Термин 2
: Определение второго термина
```

## 7. Изображения (преобразование в ASCII)

```tmkup
![Логотип](logo.png)
![Диаграмма](diagram.png {height=90})
```

- Параметр `height` задаёт желаемую высоту в символах (необязательный).
- Ширина рассчитывается автоматически на основе соотношения сторон и системы отображения с полублочными символами.
- Клиент должен преобразовать изображение в ASCII-графику.
- Если преобразование невозможно, альтернативный текст отображается в квадратных скобках.

## 9. Специальные блоки

### 9.1. Информационные блоки

Блоки начинаются с `!!!` и содержат атрибут `type` со значением `info`, `warning`, `success` или `error`.

```tmkup
!!! {type="info"}
Информационное сообщение
Поддерживается *форматирование*
!!!

!!! {type="warning"}
Важное предупреждение
!!!

!!! {type="success"}
Успешное выполнение
!!!

!!! {type="error"}
Ошибка выполнения
!!!
```

**Отображение в терминале:**
- `info` → синий цвет, префикс `[INFO]`
- `warning` → жёлтый цвет, префикс `[WARN]`
- `success` → зелёный цвет, префикс `[ OK ]`
- `error` → красный цвет, префикс `[ERR ]`

### 9.2. Цветные блоки с границей

Блоки ограничиваются маркерами `%%` и могут иметь атрибуты `color` и `border`.

```tmkup
%% {color="blue" border="left"}
Блок с левой границей
%%

%% {color="green" border="rounded"}
Блок со скруглённой границей
%%
```

**Отображение:** граница рисуется с помощью символов псевдографики (`┌─┐`, `└─┘`, `├─┤` и т. д.) указанным цветом.

### 9.3. Спойлеры (скрытое содержимое)

Спойлер начинается с `???` и может иметь атрибут `title`. Содержимое скрыто до тех пор, пока пользователь не нажмёт клавишу.

```tmkup
???
Скрытое содержимое
Отображается после нажатия Enter
???

??? {title="Показать ответ"}
Секретный ответ: **42**
???
```

В текстовом режиме спойлер отображается как `[▶] Title` (если задан заголовок) или `[▶] Spoiler`. При нажатии Enter содержимое раскрывается.

### 9.4. Цитаты

```tmkup
> Обычная цитата
> Многострочная цитата
> — Автор цитаты

> {cite="John Doe" date="2024"}
> Цитата с указанием автора и даты
```

```tmkup
| John | 25  | Москва |
```


## 11. Формы

Формы используются для отправки данных на сервер. Они заключаются между `@@` и содержат поля.

```
@@ {action="/path" method="post"}
... поля ...
@@
```

**Обязательные атрибуты формы:** `action`, `method` (допускается только `post`).

### 11.1. Текстовые поля

```tmkup
[Ваше имя] {type="text" name="username" placeholder="Имя" required}
[Электронная почта] {type="email" name="email" placeholder="user@example.com" required}
[Пароль] {type="password" name="password" required}
[Сообщение] {type="textarea" name="message" rows="4" placeholder="Текст"}
```

### 11.2. Флажки

```tmkup
[Я согласен с условиями] {type="checkbox" name="agree" checked}
[Подписаться на рассылку] {type="checkbox" name="newsletter"}
```

### 11.3. Радиокнопки (блочный синтаксис)

```
[radio name="gender"]
  [Мужской] {value="male" checked}
  [Женский] {value="female"}
[/radio]
```

### 11.4. Выпадающий список (блочный синтаксис)

```
[select name="city"]
  [Москва] {value="msk" selected}
  [Санкт-Петербург] {value="spb"}
  [Казань] {value="kzn"}
[/select]
```

Множественный выбор:

```
[select name="tags" multiple]
  [Новости] {value="news" selected}
  [Блог] {value="blog"}
  [Статьи] {value="articles" selected}
[/select]
```

### 11.5. Кнопки

```tmkup
[Отправить] {type="submit"}
[Сбросить] {type="reset"}
```

### 11.6. Скрытое поле

```tmkup
[ ] {type="hidden" name="token" value="abc123"}
```

### 11.7. Полный пример формы

```tmkup
@@ {action="/register" method="post"}

[Ваше имя] {type="text" name="username" placeholder="Имя" required}
[Электронная почта] {type="email" name="email" placeholder="user@example.com" required}
[Пароль] {type="password" name="password" required}

Страна:
[select name="country"]
  [Россия] {value="ru" selected}
  [США] {value="us"}
  [Германия] {value="de"}
[/select]

[Я согласен с условиями] {type="checkbox" name="agree" required}
[Подписаться на рассылку] {type="checkbox" name="newsletter" checked}

Пол:
[radio name="gender"]
  [Мужской] {value="male" checked}
  [Женский] {value="female"}
[/radio]

[Комментарий] {type="textarea" name="message" rows="4"}

[Отправить] {type="submit"}
[Сбросить] {type="reset"}

@@
```

## 14. Переменные

Переменные определяются в блоке метаданных и используются с помощью конструкции `{{ variable }}`.

```tmkup
---tmk-meta
variables:
  site_name: "TNet Hub"
  date: "2024-06-10"
---tmk-meta

Добро пожаловать на {{ site_name }}.
Сегодня: {{ date }}.
```
