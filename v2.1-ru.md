# TMkUp — Спецификация языка разметки

**Версия:** 2.1  
**Статус:** Draft  
**Расширение файлов:** `.tmkup`

## 1. Введение

TMkUp — язык разметки, предназначенный для создания структурированных текстовых документов с поддержкой форматирования, списков, таблиц, изображений, блоков кода, специальных блоков и интерактивных элементов.

Версия 2.1 сохраняет возможности версии 2.0 и расширяет оформление блочных элементов: добавляет новые стили границ, параметры цвета, заголовки и настройки отображения.

Спецификация описывает весь язык TMkUp, включая возможности, унаследованные от версии 2.0.

## 2. Общие правила

### 2.1. Синтаксис

TMkUp использует текстовые конструкции и специальные маркеры для определения структуры документа.

Параметры элементов задаются в фигурных скобках:

```tmkup
{parameter="value"}
```

Значения параметров заключаются в двойные кавычки.

### 2.2. Блочные элементы

Блочными элементами являются конструкции, которые формируют отдельные структурные области документа: специальные блоки, таблицы, формы и другие подобные элементы.

### 2.3. Общие параметры блочных элементов

По умолчанию все блочные элементы поддерживают общий набор блочных параметров:

| Параметр | Назначение |
|---|---|
| `title` | Заголовок блока |
| `color` | Цвет текста и, если не задан отдельный цвет границы, цвет границы |
| `border-color` | Цвет границы |
| `border` | Стиль границы |
| `padding` | Внутренние отступы |
| `align` | Выравнивание содержимого |
| `title-align` | Выравнивание заголовка |
| `title-color` | Цвет заголовка |
| `collapsible` | Возможность сворачивания блока |

Отдельные блочные элементы могут явно запрещать использование некоторых параметров. Если параметр запрещён для конкретного элемента, он не может использоваться с этим элементом.

Правила отдельных элементов и их ограничения описаны в соответствующих разделах.

### 2.4. Цвета

TMkUp поддерживает именованные цвета, предназначенные для отображения в терминале.

Поддерживаются обычные цвета переднего плана, яркие цвета переднего плана, цвета фона и яркие цвета фона.

Примеры:

```tmkup
{red}Красный текст{/red}
{green}Зелёный текст{/green}
{bg-blue}Текст на синем фоне{/bg-blue}
{bred}Яркий красный текст{/bred}
{bg-bred}Текст на ярком красном фоне{/bg-bred}
```

Цветовые конструкции могут быть вложенными:

```tmkup
{red}
Красный текст и {bold}жирный красный текст{/bold}.
{/red}
```

Конструкция `{/}` сбрасывает текущие цветовые настройки.

## 3. Метаданные документа

Метаданные задаются в начале документа с помощью блока `---tmk-meta`.

```tmkup
---tmk-meta
title: "Document Title"
author: "Author Name"
version: "2.0"
created: "2024-06-10"
variables:
  site_name: "TNet Hub"
---tmk-meta
```

Метаданные могут содержать произвольные ключи.

Поле `variables` предназначено для определения переменных, которые впоследствии можно использовать в тексте документа.

## 4. Заголовки

TMkUp поддерживает шесть уровней заголовков.

```tmkup
# Заголовок первого уровня #

## Заголовок второго уровня ##

### Заголовок третьего уровня ###

#### Заголовок четвёртого уровня ####

##### Заголовок пятого уровня #####

###### Заголовок шестого уровня ######
```

Количество символов `#` определяет уровень заголовка.

## 5. Форматирование текста

### 5.1. Основные стили

| Синтаксис | Результат |
|---|---|
| `*текст*` | Курсив |
| `**текст**` | Жирный текст |
| `***текст***` | Жирный курсив |
| `` `текст` `` | Строчный код |

Пример:

```tmkup
*Курсивный текст*

**Жирный текст**

***Жирный курсив***

`inline code`
```

### 5.2. Дополнительные стили

Следующие возможности являются опциональными:

| Синтаксис | Назначение |
|---|---|
| `~~текст~~` | Зачёркнутый текст |
| `==текст==` | Выделенный текст |
| `^текст^` | Надстрочный текст |
| `~текст~` | Подстрочный текст |

Поддержка этих конструкций не является обязательной для каждой реализации TMkUp.

## 6. Горизонтальные разделители

Для создания горизонтального разделителя используются:

```tmkup
---
```

или

```tmkup
***
```

## 7. Списки и задачи

### 7.1. Ненумерованные списки

Ненумерованные списки создаются с помощью `-`.

```tmkup
- Первый элемент
- Второй элемент
- Третий элемент
```

Вложенность определяется отступами:

```tmkup
- Первый элемент
  - Вложенный элемент
  - Ещё один вложенный элемент
- Второй элемент
```

### 7.2. Нумерованные списки

Нумерованные списки создаются с помощью чисел и точки.

```tmkup
1. Первый элемент
2. Второй элемент
3. Третий элемент
```

### 7.3. Задачи (Task)

Задача представляет собой обычный элемент checkbox, а не отдельный тип списка.

Поддерживаются следующие состояния:

| Маркер | Состояние |
|---|---|
| `[ ]` | Не выполнено |
| `[x]` | Выполнено |
| `[~]` | В процессе |

Пример:

```tmkup
[ ] Не выполненная задача
[x] Выполненная задача
[~] Задача в процессе
```

Задачи могут использоваться самостоятельно или как элементы обычного списка:

```tmkup
- [ ] Первая задача
- [x] Вторая задача
- [~] Третья задача
```

Список и задача являются самостоятельными конструкциями: маркер списка определяет структуру списка, а маркер задачи — состояние checkbox.

### 7.4. Списки определений

Список определений использует отдельную строку с двоеточием перед определением.

```tmkup
Термин
: Определение термина

Другой термин
: Его определение
```

## 8. Ссылки и изображения

### 8.1. Ссылки

Ссылки задаются следующим образом:

```tmkup
[Текст ссылки](/path/to/doc.tmkup)
```

Первый параметр содержит отображаемый текст, второй — адрес ссылки.

Поддержка всплывающих подсказок для ссылок отсутствует.

### 8.2. Изображения

Изображения задаются с помощью конструкции:

```tmkup
![Описание изображения](image.png)
```

Можно указать высоту изображения:

```tmkup
![Диаграмма](diagram.png {height=90})
```

Параметр `height` задаёт высоту изображения в символах терминала.

Ширина рассчитывается автоматически на основе соотношения сторон изображения.

При отображении в терминале клиент должен преобразовать изображение в ASCII-представление с использованием полублочных символов.

Если изображение невозможно отобразить, вместо него используется альтернативный текст в квадратных скобках.

## 9. Блоки кода

### 9.1. Строчный код

Для отображения кода внутри строки используются обратные кавычки:

```tmkup
Используйте `print()` для вывода текста.
```

### 9.2. Многострочный код

Для многострочных блоков кода используются тройные обратные кавычки.

После открывающей последовательности можно указать язык программирования.

````tmkup
```python
def hello():
    print("Hello World!")
```
````

### 9.3. Вложенные блоки кода

Для создания вложенного блока кода внутри другого блока необходимо использовать более длинную последовательность обратных кавычек для внешнего блока.

Например, четыре обратные кавычки позволяют разместить внутри блока обычную последовательность из трёх обратных кавычек:

``````tmkup
````text
```python
def hello():
    print("Hello World!")
```
````
``````

Внешняя последовательность должна быть длиннее последовательности, используемой во вложенном блоке.

## 10. Специальные блоки

### 10.1. Информационные блоки

Информационные блоки создаются с помощью `!!!`.

Поддерживаются четыре типа:

| Тип | Назначение | Стандартный цвет | Заголовок |
|---|---|---|---|
| `info` | Информация | Синий | `INFO` |
| `warning` | Предупреждение | Жёлтый | `WARNING` |
| `success` | Успешное выполнение | Зелёный | `OK` |
| `error` | Ошибка | Красный | `ERR` |

Пример:

```tmkup
!!! {type="info"}
Информационное сообщение.
!!!

!!! {type="warning"}
Предупреждение.
!!!

!!! {type="success"}
Операция успешно завершена.
!!!

!!! {type="error"}
Произошла ошибка.
!!!
```

В терминале типы блоков также могут отображаться с соответствующими префиксами:

- `[INFO]`
- `[WARN]`
- `[ OK ]`
- `[ERR ]`

**Ограничения параметров:**

- `title` запрещён: заголовок определяется типом блока.
- `border-color` не поддерживается.
- `color` изменяет только цвет содержимого. Заголовок и граница сохраняют стандартные цвета соответствующего типа.

### 10.2. Блоки с границей

Блоки с границей создаются с помощью `%%`.

```tmkup
%%
Содержимое блока.
%%
```

Блок может принимать общие параметры блочных элементов.

Пример:

```tmkup
%% {title="Пример" color="cyan" border="rounded"}
Содержимое блока.
%%
```

Стиль границы по умолчанию — `rounded`.

### 10.3. Спойлеры

Спойлеры создаются с помощью `???`.

```tmkup
??? 
Скрытое содержимое.
???
```

Можно указать собственный заголовок:

```tmkup
??? {title="Дополнительная информация"}
Скрытое содержимое.
???
```

Если заголовок не указан, используется заголовок `SPOILER`.

По умолчанию спойлер отображается в свёрнутом состоянии:

```text
[▶] SPOILER
```

При использовании собственного заголовка:

```text
[▶] Дополнительная информация
```

Для раскрытия спойлера используется клавиша Enter.

Спойлеры поддерживают общие параметры блочных элементов, если конкретный параметр не запрещён для этого элемента.

## 11. Таблицы

### 11.1. Обычные таблицы

TMkUp поддерживает стандартный синтаксис Markdown-таблиц.

```tmkup
| Имя | Возраст |
|-----|---------|
| John | 25 |
| Alice | 30 |
```

Поддерживается выравнивание столбцов с помощью стандартных маркеров:

```tmkup
| Слева | По центру | Справа |
|:------|:---------:|-------:|
| Текст | Текст     | Текст  |
```

### 11.2. Оформленные таблицы

В версии 2.1 добавляется возможность оборачивать таблицу в специальный блок `@@table`.

```tmkup
@@table {title="Пользователи" color="cyan" border-color="blue" border="rounded"}
| Имя | Возраст |
|-----|---------|
| John | 25 |
| Alice | 30 |
@@
```

Блок таблицы поддерживает следующие параметры:

| Параметр | Назначение |
|---|---|
| `title` | Заголовок таблицы |
| `color` | Цвет текста и границы, если не задан `border-color` |
| `border-color` | Цвет границы |
| `border` | Стиль границы |
| `padding` | Внутренние отступы |
| `align` | Выравнивание содержимого |
| `title-align` | Выравнивание заголовка |
| `title-color` | Цвет заголовка |
| `collapsible` | Возможность сворачивания |

Допустимые значения параметра `border`:

- `rounded`
- `left`
- `top`
- `bottom`
- `vertical`
- `none`

Значение `vertical` означает отображение обеих вертикальных сторон границы.

Если `title` не задан, заголовок таблицы отсутствует.

Обычные Markdown-таблицы продолжают поддерживаться независимо от `@@table`.

## 12. Формы

### 12.1. Общий синтаксис

Формы создаются с помощью конструкции `@@`.

```tmkup
@@ {action="/path" method="post"}
...
@@
```

Обязательные параметры:

| Параметр | Назначение |
|---|---|
| `action` | Адрес отправки формы |
| `method` | Метод отправки |

Поддерживается метод `post`.

### 12.2. Поля формы

Формы поддерживают следующие элементы:

- Текстовое поле (`text`)
- Поле электронной почты (`email`)
- Поле пароля (`password`)
- Многострочное текстовое поле (`textarea`)
- Флажок (`checkbox`)
- Группа переключателей (`radio`)
- Выпадающий список (`select`), включая множественный выбор
- Скрытое поле (`hidden`)
- Кнопка отправки (`submit`)
- Кнопка сброса (`reset`)

### 12.3. Оформление форм

В версии 2.1 формы поддерживают параметры оформления блочных элементов.

Пример:

```tmkup
@@ {action="/submit" method="post" title="Форма" color="cyan" border-color="blue" border="rounded"}
...
@@
```

Поддерживаются:

- `title`
- `color`
- `border-color`
- `border`
- `padding`
- `align`
- `title-align`
- `title-color`
- `collapsible`

Для цветов действуют общие правила блочных элементов.

## 13. Сноски

Сноски задаются с помощью маркеров `[^id]`.

Пример:

```tmkup
Это текст со сноской[^1].

[^1]: Текст сноски.
```

Маркер в тексте связывается с соответствующим определением сноски.

## 14. Комментарии

TMkUp поддерживает однострочные и многострочные комментарии.

### 14.1. Однострочные комментарии

```tmkup
// Это комментарий
```

### 14.2. Многострочные комментарии

```tmkup
/*
Это многострочный
комментарий.
*/
```

Комментарии не являются отображаемым содержимым документа.

## 15. Переменные

Переменные определяются в блоке метаданных и используются в тексте документа с помощью двойных фигурных скобок.

Пример определения:

```tmkup
---tmk-meta
variables:
  site_name: "TNet Hub"
---tmk-meta
```

Использование:

```tmkup
Добро пожаловать на {{ site_name }}!
```

При обработке документа переменная заменяется соответствующим значением из метаданных.

## 16. Параметры границ

Для блочных элементов доступны следующие стили границ:

| Значение | Описание |
|---|---|
| `rounded` | Скруглённая граница |
| `left` | Только левая граница |
| `top` | Только верхняя граница |
| `bottom` | Только нижняя граница |
| `vertical` | Левая и правая границы |
| `none` | Без границы |

Поддержка конкретного стиля определяется возможностями элемента и его ограничениями.

## 17. Правила обработки цветов блочных элементов

Для обычных блочных элементов, включая `%%`, `???`, формы и оформленные таблицы, действуют следующие правила:

1. Если задан только `color`, он применяется к содержимому и границе.
2. Если задан только `border-color`, он применяется только к границе.
3. Если заданы оба параметра, `color` применяется к содержимому, а `border-color` — к границе.

Для `!!!` действуют отдельные правила, описанные в разделе 10.1.
